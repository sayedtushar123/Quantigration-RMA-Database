# Quantigration RMA — Data Analysis

## Project Overview

This project analyzes return merchandise authorization (RMA)
records using MySQL.

The analysis focuses on:
- Number of returns by state
- Percentage of returns by product type
- Data quality verification
- Business recommendations

## Key Findings

- Total RMA records analyzed: 37,566
- States included in the analysis: 48
- Product types analyzed: 9
- Highest returns by state: Massachusetts (972)
- Highest returns by product type: Basic Switch 48-port (22.05%)

## Technologies

- MySQL 8.0
- SQL
- Relational databases
- Data analysis
- SQL JOIN and GROUP BY
